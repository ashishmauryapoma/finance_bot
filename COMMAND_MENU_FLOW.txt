 4. TELEGRAM API CALL
═══════════════════════════════════════════════════════════════════════════════

   HTTP Request:
   ─────────────
   POST https://api.telegram.org/bot{TOKEN}/setMyCommands
   
   Request Body:
   ─────────────
   {
     "commands": [
       {"command": "start", "description": "Start bot & login"},
       {"command": "recent", "description": "Show last 10 transactions"},
       {"command": "summary", "description": "Monthly income/expense summary"},
       {"command": "balance", "description": "View net balance & goals breakdown"},
       {"command": "goal", "description": "Manage savings goals (set/add/view/break/list)"},
       {"command": "logout", "description": "Log out from bot"},
       {"command": "help", "description": "Show help & all available commands"}
     ]
   }
   
   Response:
   ────────
   {"ok": true}
   
   OR (on error):
   {
     "ok": false,
     "error_code": 400,
     "description": "Bad Request: ..."
   }
